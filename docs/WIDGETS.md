# 桌面小组件

1.4 新增十种模板。桌面网格占用与实际显示尺寸由启动器决定。

| 模板 | 展示内容 |
| --- | --- |
| 1×2 精简实况 | 当前温度、天气与体感 |
| 2×2 当前天气 | 实时天气、体感与高低温 |
| 2×4 小时预报 | 当前天气及逐小时预报 |
| 2×4 五日预报 | 未来五天的天气与高低温 |
| 4×4 天气概览 | 实况、小时预报及未来六日天气 |
| 2×2 空气质量 | AQI、等级及参考条 |
| 2×2 未来降雨 | 未来降水概率与趋势 |
| 2×4 降雨趋势 | 更宽的降水概率趋势图 |
| 2×4 多城天气 | 两城或三城的实时、体感及高低温 |
| 4×4 今日概览 | 当日天气摘要、温度指示、环境范围及生活建议 |

## 添加与编辑

在系统桌面的小组件列表中选择“云松天气”，也可从天气设置进入小组件管理。首次添加后完成城市选择；多城模板要求前两城有效，第三城可选择“不显示”，全部选择完成后统一保存。

已配置组件点击天气进入对应城市；点击更新时间或在管理页编辑城市。系统支持时，也可长按组件进入编辑。跟随定位使用应用已保存的定位城市，不会持续请求位置。

## 刷新与数据

组件与首页共用按城市和天气源区分的缓存，天气过旧时标注缓存状态。在管理页可立即刷新、查看状态或恢复刷新与通知排程。系统省电、网络和权限可能延迟后台更新。

温度和风速等遵循应用单位设置；空气质量数值保持正常文字色，等级文字按 AQI 着色。普通城市名省略末尾“市”，完整地址保留行政区划名称。

没有取得的数据保留缺失状态，不生成假天气。免费源与自填 API 的覆盖范围不同，见 [天气源说明](OPEN_METEO.md)。
