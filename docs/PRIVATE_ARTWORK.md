# 公开源码与可选私有图标

## 默认公开构建

本仓库不包含旧天气/生活建议素材包的 87 个原 SVG，不包含旧目录的删除前 Git 历史，也不以编码、压缩或加密文件变相分发它们。
`PublicWeatherIconRenderer` 提供新绘制的基础几何图标：晴天、月亮、云、降雨、降雪、雷暴、雾、风及日出日落。
这些简化图标与维护者个人构建中的原图标**外观不同**，但查询数据、图表、导航和卡片功能相同。

## 在自己的电脑使用已获许可的素材

取得原作者允许的素材后，在仓库外建立目录，例如：

```text
D:/private-assets/weather-app/
  weather/
    tq-1.svg
    yewan.svg
    duoyun.svg
    yin.svg
    xiaoyu.svg
    ...
    richu.svg
    riluo.svg
  life_advice/
    （旧生活建议 SVG 可选，现有生活建议由代码绘制）
```

构建时传入 `-PprivateIconAssetsDir="D:/private-assets/weather-app"`。
素材按既有文件名加载并优先使用；不存在的项目安全回退到简化图标。路径本身不编译成凭证或写入代码。
不要把私有目录、含原图标的旧源码 ZIP 或其 Git 历史提交/上传到本仓库。

## 保护边界

只保证原 SVG 不在公开源码和公开 Git 历史中，不保证其在 APK 中不可提取。
APK 内素材、运行时内存及屏幕显示仍可能被分析、提取或截图。把素材改为加密资源只能提高分析成本，不能产生绝对防逆向能力，也不能替代原作者许可。

代码采用 GPL-3.0-only，第三方素材保持独立许可；没有把非商用素材改标为 GPL，也没有对 GPL 代码附加非商用限制。
