# 云松天气 1.5

<!-- yunsong-version-code: 13 -->

1.5 优化了首页启动、大字号排版、降雨提醒、免费天气与 API 指引，以及部分天气小组件的显示。

## 优化

- **应用内更新**。发现新版本后，可在 App 内确认并下载安装包。下载和校验完成后，直接进入 Android 安装确认。
- **启动与首页入场**。提升 App 打开速度，天气背景、文字和卡片分层载入，首页过渡更流畅自然。
- **大字号显示**。优化大字号下的布局和换行，让文字、图表和其他界面元素在可用空间内完整显示。
- **降雨提醒**。调整通知文案与提醒方式。预报无变化时减少重复推送，雨将结束且后续持续无雨，或未来半小时内雨势突然增强到中雨及以上时，优先提醒。
- **免费天气与 API 指引**。优化免费天气源提醒弹窗、API 配置页和教程的显示。教程进一步说明注册、申请和填写步骤，方便跟着操作。
- **天气小组件**。优化部分桌面天气小组件的文字显示和排版，让信息更易读。

## 修复

- 修复首页首屏位置跳动，以及指标卡长说明被裁切的问题。
- 修复 48 小时图表横滑失效、降水读数重叠和风速单位断行。
- 恢复空气质量详情六项污染物指示条的彩色填充，适配深浅色模式。
- 修复高降水概率时小组件数值与柱形挤压，以及降雨短暂停歇或预报取消时的误提醒。
- 修复单个系统定位服务失败后可能阻断后续定位的问题。地址解析超时时仍可使用位置获取天气。

## 下载与升级

- 安装包为 **yunsong-weather-1.5.apk**，支持 Android 7.0 及以上。
- 工程源码为 **yunsong-weather-1.5-source.zip**。使用 **SHA256SUMS.txt** 校验下载文件。
- 正式签名与此前发布一致，可覆盖安装并保留城市、天气 API 设置和小组件。不同签名的旧测试版需要先保存配置。

## 数据说明

Open-Meteo 免费天气可直接使用。彩云、和风支持范围以个人 API 权限及应用内检测结果为准。降雨提醒需要所选天气源返回相应的分钟预报，并取决于系统通知与后台权限。
