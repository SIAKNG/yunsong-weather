# 云松天气 1.6

<!-- yunsong-version-code: 14 -->

1.6 加入两款时钟天气小组件和问题诊断功能，并改进了数据刷新、天气详情和提醒。

## 新增

- 新增了两款 2×4 时钟天气小组件。小时款显示未来 6 小时预报，五日款显示未来 5 天预报，两款都显示实时钟、公历、农历和当前天气。
- 新增了完整的问题诊断与记录功能，帮助用户更方便、更快地定位 App 问题。

## 优化

- 优化了进入 App 后的数据刷新逻辑和回弹动画，刷新与回弹更自然。
- 优化了首页和城市预览的顶部磨砂、深浅色弹窗及预警、降雨趋势卡片的出现动画。
- 优化了多日天气详情页的显示内容，让天气数据更直观、更准确。
- 优化了天气预报和各类预警提醒，文案更清楚、更贴近日常表达，方便理解天气变化和应对建议。
- 优化了定位和相关权限的设置入口，可以更快跳转到对应的系统设置界面。
- 优化了 App 的存储占用和缓存清理机制，大幅缩减了安装包体积。
- 优化了免费天气源弹窗的文案和显示内容，让数据范围和关闭提醒的方法更清楚。
- 优化了部分情况下的刷新流程，降低了刷新失败的概率。

## 修复

- 修复了冷启动时首页短暂空白、内容自上而下展开的问题。
- 修复了定位坐标小幅变化后首页可能找不到上次天气，以及历史曲线缺少已获取数据的问题。
- 修复了同城同日的每日天气提醒与首页最高、最低温可能不一致的问题。
- 修复了系统字号放大时部分小组件文字显示不完整的问题。
- 修复了 Open-Meteo 主天气请求遇到可恢复的网络错误时直接失败，以及失败后再次刷新可能仍在等待旧空气质量请求的问题。

## 下载与升级

- 安装包为 **yunsong-weather-1.6.apk**，支持 Android 7.0 及以上。
- 工程源码为 **yunsong-weather-1.6-source.zip**。可用 **SHA256SUMS.txt** 核对下载文件。
- 沿用此前的发布签名，可覆盖安装并保留城市、天气 API 设置和小组件。

## 数据说明

未填写个人接口时可直接使用 Open-Meteo。彩云、和风的数据范围取决于个人 API 权限，应用可检测配置。降雨提醒需要天气源提供分钟预报，也取决于系统通知和后台权限。
