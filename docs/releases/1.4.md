# 云松天气 1.4

<!-- yunsong-version-code: 10 -->

发布日期：2026-11-05

本次更新重点新增桌面天气卡片，统一城市与编辑体验，并完善刷新和提醒。未填写个人 API 时可直接使用 Open-Meteo，也可配置自己的彩云或和风接口。

## 本次更新

- **新增十种桌面天气卡片**：提供精简实况、当前天气、小时及五日预报、六日天气概览、空气质量、未来降雨、降雨趋势、多城天气与今日概览，按需展示体感、天气趋势和当日生活建议。
- **完善双城三城与城市体验**：支持两城、三城等宽布局，集中展示实时温度、体感、天气和高低温；前两城必选，第三城可隐藏，完整配置后统一保存。普通城市名统一省略末尾“市”字，详细地址保留完整写法；修复城市指示错位，重新进入时优先显示定位或首城。
- **统一卡片显示与编辑样式**：背景和图标随天气及昼夜变化，统一圆角、高光、内边距与字体层级；优化天气图文对齐及长文字、负温、不同单位下的显示，空气等级着色并与指数底部对齐。小组件管理、编辑及城市选择使用统一圆角分组。
- **完善天气刷新与排程恢复**：桌面组件与首页共用按城市、天气源隔离的缓存，显示更新时间与缓存状态；支持定时及手动刷新、状态排查与排程恢复，改善启动、重启、升级后的恢复和刷新重试。
- **提升天气提醒可靠性**：每日天气和晚间变温提醒提前准备预报，到点优先读取本机内容发送；降雨、预警独立取数并支持失败重试。修复反复检查推迟提醒、旧缓存覆盖新判断等问题，完善补发、切换来源隔离与去重。

## 下载与升级

- 安装包：`yunsong-weather-1.4.apk`。
- 工程源码：`yunsong-weather-1.4-source.zip`。
- 文件校验：`SHA256SUMS.txt`。
- Android 7.0 及以上；应用内版本 `1.4-userapi`，构建号 `10`，显示名称仍为“云松天气”。
- 与此前正式版使用相同签名，可覆盖升级并保留城市、API、设置及已有桌面组件。不同签名的旧测试版不能直接覆盖，请勿贸然卸载导致配置丢失。

## 数据说明

小组件展示接口实际返回或已缓存的数据，缺失字段不补造；天气、空气质量、降雨趋势及提醒能力取决于所选天气源及权限。免费源不提供中国雷达分钟预报、国内官方预警和完整生活指数。本机提醒受系统后台及通知权限影响，不能替代官方预警。
