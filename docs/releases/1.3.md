# 云松天气 1.3

<!-- yunsong-version-code: 8 -->

发布日期：2026-10-29

本次更新重点改善多日预报的查看方式、天气加载与页面交互体验。未填写个人 API 时仍可直接使用 Open-Meteo；也可配置自己的彩云或和风天气接口。

## 本次更新

- 多日预报按日期直达：点击首页列表或折线中的某一天，即可打开对应日期的详情；每一天都有独立摘要、逐小时图表和“返回今日”入口。
- 重构多日详情图表：由原先在同一列表或图表中集中展示所有日期，改为每一天独立显示当天的天气摘要及下方可切换指标的图表。图表统一渐变与高亮样式，温度、体感合并对照并显示温差。
- 完善当天与历史展示：小时图按 00:00–23:00 组织；跨天保留已取得的同源小时预报，未获取的时段保留空缺。
- 加快免费天气加载：Open-Meteo 天气与空气质量并行请求，天气先展示，空气质量随后补齐。
- 改善返回主页时偶发内容不显示的问题，修复卡片进入、退出详情时毛玻璃短暂变清晰的问题。
- 优化检查更新：点击后显示检查进度；仅在确认有新版本时打开下载页，无更新或检查失败时留在设置页显示结果。

## 下载与升级

- 安装包：`yunsong-weather-1.3.apk`。
- 工程源码：`yunsong-weather-1.3-source.zip`。
- 文件校验：`SHA256SUMS.txt`。
- Android 7.0 及以上；应用内版本 `1.3-userapi`，构建号 `8`，显示名称仍为“云松天气”。
- 与此前正式版使用相同签名，可覆盖升级并保留城市、API 和设置。不同签名的旧测试版不能直接覆盖，请勿贸然卸载导致配置丢失。

## 数据说明

小时预报和历史内容取决于接口权限及已取得的数据；本机保存的历史预报不是气象站实测。免费源不包含中国雷达分钟预报、国内官方预警和完整生活指数，相关功能需要支持它们的个人接口。
