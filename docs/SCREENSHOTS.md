# 文档截图说明

## 数据与隐私

- 仅使用北京、上海城市级示例，不包含维护者当前位置、街道、小区或真实私人城市列表。
- 气象数值、曲线、生活建议和预警均为模拟内容。预警标明“演示/并非真实预警”，不是气象台实报。
- 全幅展示图有测试层的模拟数据水印；水印不属于正式应用必须显示的内容。
- 不截取真实 Token、API Key、个人 API Host、剪贴板、私人通知或账号资料。
- API 配置页保留 FLAG_SECURE，不关闭防截图保护；文档展示只读申请教程。
- 裁掉系统状态栏和导航区并等比例缩放，没有拉伸界面。

## 界面来源

截图在真机使用本仓库原生 Activity、自定义图表和卡片渲染，不采用其他 App 或外部概念稿。
天气主页布局借城市预览宿主复用同一 WeatherFragment，在测试层展示原生地址/设置栏，
不进入用户真实定位首页，也不把演示城市保存成收藏城市。
其他详情、城市管理、预警、生活建议、设置、教程和引导使用各自原生页面。

夹具直接向视图及 Intent 提供虚拟数据，不将模拟预警写进通知台账，不推送模拟预警。
城市列表的北京/上海演示摘要仅临时使用，结束后恢复原摘要缓存和主题；加密接口配置不改写。
采集结束另做配置摘要核对。测试代码不进入正式 APK。

截图采用维护者本机独立许可图标，公开源码不带原 SVG，默认简化图标会有所不同。
这些截图不将其中的第三方图标和商标重新授权为 GPL。

## 维护

ShowcaseScreenshotTest 位于 app/src/androidTest，仅在显式传入 capture_showcase=true 时执行，默认跳过。
使用匹配目标签名的测试包及专用设备；不要在日用设备运行会卸载应用的测试任务。
导出图片位于 docs/screenshots/showcase/，不附原始全屏、接口响应、位置缓存或设备日志。
