# 胶囊选中区域与检查更新

## 多日详情胶囊（两版）

- 选中块直接按当前选项的实际宽高计算，四周均留2dp。修复前真机测到合并项左边距7像素、右边距11像素；修复后宽选项、普通选项及首尾切换都使用相同的对称留白。
- 字号变化时按文字实际宽度增加选项空间；连续切换以当前已绘制的宽度继续动画，保留位置、宽度与文字色的260毫秒过渡。
- 浅色使用蓝灰底座、乳白选中填充与1dp白色描边。深色使用深蓝灰底座与较亮的蓝灰选中填充。
- 按追加要求，深色描边调整为0.75dp、64%白色，减弱原来过亮、过宽的效果；浅色描边及现有滑动动画保持。
- 仅调整多日详情指标胶囊，不改主页卡片、图表曲线、高亮点或天气数据。

## 检查更新（现有自填版入口）

- 点击先显示“正在检查更新…”及主题色的旋转进度圈。保留至少400毫秒反馈；检查中重复点击不重复发请求。
- 手动检查绕过自动检查的6小时成功缓存与10分钟失败退避。自动检查继续复用原缓存。
- 只有主动点击后确认存在较新的可安装Release，才打开现有GitHub下载页。无更新、接口不可用及检查失败均停留在设置页并显示结果；自动发现新版只显示提醒。
- 较早的自动请求不能覆盖较新的手动结果或缓存。离开页面后不会突然打开浏览器；检查完成后短期返回设置页保留结果，避免立即重复转圈。
- 仅请求公开Release信息，沿用应用版本User-Agent，不发送天气API信息、位置或账号凭证。内置版原本没有该GitHub下载入口，保留其原设置功能。

## 验证方式

尺寸测试读取真机实际绘制边界；描边测试采样真实Drawable像素，并检查两种主题下的文字对比度。更新流程采用可控响应覆盖当前版本、新版本、失败和不可用，以及重复点击、强制刷新缓存、并发旧结果；下载Intent被测试监视器拦截，不实际打开模拟版本页面。截图只使用应用窗口，避免采到系统通知等私人信息。
