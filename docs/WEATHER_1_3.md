# 1.3 天气加载、转场与逐日图表

## 显示与交互

- 多日预报保留首页按行/列直达日期、日期分页和日期条；下方切换为六项气象指标实际共用的 `HourlyMetricChartView`，使用相同填充、网格、渐变和 `ChartSelectionMarker`。
- 温度、体感、降水、风力、紫外线、湿度、气压、能见度、空气质量九项合并在一个胶囊中。使用首页折线/列表切换的底座和内部滑块素材；只有一个选中滑块，260 毫秒减速滑动，带柔和阴影和文字颜色过渡；连续点击从当前滑块位置接续，选项没有各自独立的胶囊背景。横滑胶囊只移动选项，不切换日期。
- 摘要仍限当天；小时图表固定覆盖当天00时至23时，不以打开时刻裁掉上午。指标和小时选择随日期页面与重建恢复。
- 按追加要求，移除图表前的“当日逐小时”标题与“回到当前”按钮，整体胶囊上移；绘图区左右内边距从14dp减至6dp，扩大宽度并让回收的标题行高度分配给图表。在“信息摘要”标题最右侧放置“返回今日”磨砂胶囊，已经位于今天或今日数据不可用时禁用；48小时页面不受此布局变动影响。
- 两个版本均为1.3；关于页从构建版本动态取值。

## 免费源加载（仅自填版）

实际接入的是 **Open-Meteo**。天气与空气请求并行启动，天气成功即提交首页，空气较晚返回时独立补入，不重复结束下拉刷新，不重绘整页。30秒内同坐标并发/重复请求合并或复用内存结果；源修订检查仍在每次提交时生效。

没有删除15日预报、昨日小时、天气字段，也没有改为另外一个OpenWeather服务；仍只发送原来的两位小数坐标和应用版本，不发送API凭据、账号、设备标识或城市详情给免费源。

官方参数说明：[Open-Meteo Forecast API](https://open-meteo.com/en/docs)。

## 日期历史缓存

`ForecastDayHistoryCache`按来源、API配置修订、城市坐标分隔。每次保存成功天气响应时，在首页裁剪小时之前保存完整原始小时字段；读取时按本地日历日保留昨天与当前/未来窗口，跨天自动把已保存的前一天时段标记为历史。最多72小时未更新即失效。

已有同源数据按小时合并，新结果的空字段不抹掉旧有效值；不把日预报复制成24个小时，不使用其他来源填充。没有获取/保存过的历史时段显示缺口；这类缓存是已保存预报，不冒充监测观测。第一次使用且接口只提供未来小时的来源，无法凭空补齐此前历史。

48小时入口仍只保留过去1小时；本次完整日历日时间窗只作用于多日详情。

## 主页与毛玻璃

- 回前台/重新获焦时主动重算ViewPager2绘制状态；普通卡片采样直接绘制天气背景，不再临时将整个Fragment透明化。内容蒙版的临时排除始终在finally恢复。
- Android12及以上屏幕绘制维持原RenderEffect。软件Canvas转场截图走真实CPU模糊，复用低分辨率缓冲，不再显示清晰原图；主页填充、描边及前景内容不变。

## 验证说明

修复前普通八次前后台循环未自然复现整页空白；单独重建留存页面INVISIBLE/alpha=0状态时，旧版返回后不会自行恢复。该状态恢复测试用于验证修复，并不声称已经确认所有偶发空白的唯一原因。

修复前软件转场条纹截图对比度255，证实原路径直接绘制清晰源图。该测试保留并用于验证模糊修复。测试截图只含北京模拟天气，配置检查只输出哈希；不清除用户城市、缓存或API配置。

本批为本机安装验证，不自动上传GitHub，不修改已发布的1.1/1.2历史。
