# 多日天气按日详情

## 首页入口

- 列表整行按真实日期打开详情，不再总是从第一天开始。
- 折线卡片按列的中点边界识别点击日期；日期、天气、曲线所在的同一竖列共享一个命中区域。
- 列表采用整行阴影涟漪；图表按下时绘制整列阴影。拖动、取消及快速移动后抬手不会误开日期。
- 点卡片空白或标题仍打开当前日期；没有今天时定位到最近可用日期。

## 逐日内容与手势

- 顶部地址和标题保持固定，日期条保留七项视口、横向滚动、选中框及文字缩放。
- 每个日期是一张独立页面，使用原生 ViewPager2；在摘要区域左右滑动切换日期，在图表区域横滑只选择小时。
- 每页复用 48 小时页的当日摘要，图表使用六项指标共用的 HourlyMetricChartView；整体胶囊包含温度/体感、降水、风力、紫外线、湿度、气压、能见度、空气质量。风力读数遵循设置单位。
- 温度/体感合并为彩色体感主线和灰色实际气温参考线，当前及所选小时显示双读数和温差；缺字段不伪造零差。
- 温度范围、降水概率、风力/空气范围、防晒与穿衣建议仅由当前日期的数据构成；未来日期不套用今天的实况温度标点。
- 优先使用当前日的原始日预报高低温与概率；逐小时字段只使用该日真实返回的时刻，不复制其他日数据、不把日预报扩写成 24 个小时。
- 只有日预报、没有小时预报的日期保留已有摘要，并显示“当日逐小时数据暂未提供”。缺失字段保持缺失。
- 日期、指标及每个日期所选小时支持页面重建恢复；摘要右上角“返回今日”切换回今天，已在今天时禁用。
- 当日小时图固定为 00:00–23:00，完整响应按来源、配置修订及城市保存，跨天保留已取得的同源小时预报，未取得的时段留空；48 小时详情仍仅保留过去一小时。
