# 多日天气按日详情

## 首页入口

- 列表整行按真实日期打开详情，不再总是从第一天开始。
- 折线卡片按列的中点边界识别点击日期；日期、天气、曲线所在的同一竖列共享一个命中区域。
- 列表采用整行阴影涟漪；图表按下时绘制整列阴影。拖动、取消及快速移动后抬手不会误开日期。
- 点卡片空白或标题仍打开当前日期；没有今天时定位到最近可用日期。

## 逐日内容与手势

- 顶部地址和标题保持固定，日期条保留七项视口、横向滚动、选中框及文字缩放。
- 每个日期是一张独立页面，使用原生 ViewPager2；在摘要区域左右滑动切换日期，在图表区域横滑只选择小时。
- 每页复用 48 小时页的摘要和图表组件。逐日模式保留温度/体感、降水、风力及风向、紫外线、湿度、空气质量；风力读数遵循设置中的单位。
- 温度范围、降水概率、风力/空气范围、防晒与穿衣建议仅由当前日期的数据构成；未来日期不套用今天的实况温度标点。
- 优先使用当前日的原始日预报高低温与概率；逐小时字段只使用该日真实返回的时刻，不复制其他日数据、不把日预报扩写成 24 个小时。
- 只有日预报、没有小时预报的日期保留已有摘要，并显示“当日逐小时数据暂未提供”。缺失字段保持缺失。
- 日期选择及每个日期的小时滚动位置支持页面重建恢复。“回到当前”同时返回今天和起始小时位置。

## 两版及验证

共享组件同步用于内置接口版与自填接口/免费源版；不改天气请求、凭证、来源选择或缓存策略。

- 自填工程 158 项单元测试、内置工程 126 项单元测试通过，两版 Release 及构建要求的 lint 检查通过。
- OPPO Android 16 实机：自填版 7 项设备测试（含配置摘要）、内置版 6 项设备测试通过。
- 覆盖首页列表/图表/图表末端点击、阴影和取消、15 日日期窗口、按手势切日、图表小时横滑、缺小时数据、页面重建、回到当前、深浅色、风速单位及原 48 小时窗口回归。
- UI 测试使用北京模拟数据；截图仅采集应用窗口，不包含个人地址、凭据或系统浮窗。主题和风速单位在测试结束后恢复。

此批为本地安装实验；实际小时预报覆盖仍取决于当前天气源和接口权限。
