# 安装与版本更新

## 下载和查看更新

打开“天气设置”，在底部信息卡片中点击“检查更新”，浏览器会打开本仓库的
[最新版本下载页](https://github.com/SIAKNG/yunsong-weather/releases/latest)。
页面正文提供版本号、功能介绍和本次更新；展开 **Assets（资源）**，选择 APK 安装包下载。
当前安装包名为 `yunsong-weather-1.2.apk`，校验值见同页 `SHA256SUMS.txt`。
应用只跳转下载页，不在后台自动下载或安装。

历史版本及后续变更统一保存在 [更新记录](../CHANGELOG.md) 和各版本的 Releases 页面。

| 检查状态 | 含义 |
| --- | --- |
| 有新版本 | 有带 APK 安装包的较新正式版本，可前往下载 |
| 已是最新版本 | 已成功检查，安装版本不低于当前正式版本 |
| 暂无法检查 | 暂未取得可用的正式版本信息，可打开下载页确认 |
| 检查未完成 | 网络、限流或响应异常，请稍后重试，不表示已是最新版本 |

公开版本无需 GitHub 登录即可查看。更新请求不含天气 API 或坐标；GitHub 仍会接收 IP、
网络元数据及应用版本 User-Agent。应用不保存 GitHub Token。

## 安装注意

- 1.2 无需配置即可使用 Open-Meteo 免费天气；可选填自己的彩云 Token 或和风 API Host + API Key，不提供维护者的接口额度。
- Android 7.0 及以上可安装；具体数据范围取决于接口权限和返回内容。
- 官方包使用专用发布证书。同一证书且 versionCode 递增时可覆盖升级；其他签名的旧测试版不能直接覆盖。
- 请勿为了安装贸然卸载旧版，以免丢失 API、城市与设置。

## 后续发布约定

1. 在 [CHANGELOG.md](../CHANGELOG.md) 顶部新增版本号、日期和实际变更，同步在 README.md 版本更新区顶部新增条目；保留此前所有版本的介绍、更新内容与下载入口，不覆盖旧记录。
2. 使用 [发布说明模板](RELEASE_TEMPLATE.md) 编写对应 GitHub Release 正文，不只上传安装包。
3. 标签使用 `v1.1`、`v1.1.1` 等正式数字版本；APK 使用 `yunsong-weather-版本号.apk`。
4. 递增 Android versionCode，保持正式证书一致；正文保留 `<!-- yunsong-version-code: N -->`，N 为实际构建号。
5. 上传经过检查的自填 API APK、对应源码与 SHA-256；不上传凭证、签名私钥或私人配置。
6. 草稿、预发布、空文件或无 APK 的版本不会被当作正式更新。
7. 保留第三方图标/依赖的来源及独立许可，不把它们重新授权为代码许可证。

更新检测按有效 APK 后缀识别，不依赖固定文件名；加上版本号不会改变现有检测方式。
