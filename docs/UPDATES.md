# 安装包更新与私有审阅

## 使用方式

打开“天气设置”，下滑到底部，在合并的信息卡片点击“检查更新”。
浏览器打开本仓库最新正式 Release，选择 `yunsong-weather.apk` 下载；校验文件见同页 `SHA256SUMS.txt`。
这里只提供跳转，不在应用内执行安装或后台下载。

检查状态：

| 行尾显示 | 含义 |
| --- | --- |
| 有新版本 | GitHub 上有带 APK 的较新正式版本 |
| 已是最新版本 | 成功取得有效的正式版本，安装版本不低于它 |
| 暂无法检查 | 未找到公开版本，可能仍在私有审阅或尚无正式 Release |
| 检查未完成 | 网络、限流或响应格式问题，不代表已是最新版本 |

应用不保存 GitHub Token，也不会将天气 API 或坐标发送到 GitHub；GitHub 仍会接收请求方 IP、普通网络元数据和应用版本 User-Agent。
私有仓库的浏览器下载需要已授权账号登录。应用匿名检查返回 404 属于预期限制，不能通过打包维护者凭证解决。

## 维护者发布约定

1. 审阅阶段保持仓库 `PRIVATE`；Release 仅在私有仓库内可见，不擅自公开。
2. 仅上传自填天气 API 的正式签名 APK、校验值、经过检查的源码和发布说明。
3. 标签使用 `v1.1`、`v1.1.1` 等正式数字版本；忽略草稿、预发布和没有可用 APK 的版本。
4. 如对同一版本进行维护构建，在说明中使用 `<!-- yunsong-version-code: N -->`，其中 N 对应 Android versionCode。
   相同数字版本比较构建号；更高数字版本按版本号判断。更新时递增 versionCode，以便系统升级。
5. 发布证书必须保持一致；证书、密码、个人天气凭证与私有原 SVG 不进入 Git。
6. 原第三方图标若保留在安装包中，仍适用其独立许可，不能保证无法提取。源码默认使用独立简化图标。

## 校验范围

更新策略单测覆盖新旧版本、维护构建、草稿/预发布、APK 缺失、外部下载地址、空文件、404、限流、错误响应。
设备测试核对深浅色下合并卡片、新版本状态、跳转目标及升级后加密配置摘要保持不变；测试截图只取设置卡片区域。
