# Open-Meteo 免费默认天气源

本地开发构建 6（1.1-userapi），2026-10-25；尚未更新 GitHub 正式附件。

## 选择规则

- 未填写完整个人接口时，默认 Open-Meteo，无需账户和 Key。
- 填写彩云 Token 后优先使用彩云；仅填完整和风 Host + API Key 则使用和风。
- 两者都填写时可指定彩云或和风主源；自动模式优先彩云。
- 个人接口网络失败/额度不足时提示所选来源错误，不自动请求免费源或把免费数值伪装成个人源。
- 清除个人接口配置后回到免费来源，不清除收藏城市。只填半套和风配置不能保存，避免错误识别。

## 实测范围

北京、上海真实请求，以及 Android 16 真机原生页面验证。返回时间范围会随请求时刻和模型变化。
天气请求配置 forecast_days=15、past_days=1：返回 384 个小时点、16 个日期，其中包含历史日。
以 2026-10-25 晚间为例，当前起气温/体感有效约 338 小时；不能把“15个日历日”宣传为从当前起完整360小时。

| App 内容 | 状态 | 数据性质及边界 |
| --- | --- | --- |
| 当前天气/温度/天气现象 | 支持 | 模型当前天气，非附近气象站直接观测 |
| 48小时温度与体感图表 | 支持 | 当前点与首页共用同一快照，未来按原始时间戳对齐 |
| 多日预报及逐小时详情 | 支持 | 15个预报日期，变量有效长度按返回数据展示 |
| 风速/风向/阵风、湿度 | 支持 | 保留原值及单位，不把缺失值当零 |
| 气压/能见度 | 支持 | 气压统一为hPa、能见度统一为km显示 |
| 逐小时紫外线 | 支持 | 使用uv_index，不把辐射或晴空紫外线冒充实际小时UV |
| 降雨概率/小时雨量 | 支持 | 小时模型预报，不是雷达临近降水 |
| 历史一小时、昨日24小时对比 | 支持 | 来自模式/历史预报，不称实测；展示范围按原有卡片规则 |
| AQI和六项污染物 | 部分支持 | 模型浓度、CO单位转换及参考AQI估算；非中国监测站官方AQI，时长短于天气预报 |
| 日出日落/昼长 | 支持 | 源提供日出日落；轨迹、晨昏、霞光说明本地计算 |
| 中国雷达分钟降雨 | 不支持 | 不用小时数据插值冒充分钟预报，不编造无雨结论 |
| 国内官方灾害预警 | 不支持 | 不伪造预警；个人API可用时由对应链路提供 |
| 和风式全量生活指数 | 不支持 | 免费源不返回原始官方指数；详情通用说明不是官方生活指数 |
| 全国空气排名 | 独立功能 | 仍取独立官方数据，不用模型城市列表伪造官方名次；不可用时明确提示 |

接口检测页面按实际响应生成支持表格。上述项目分组是能力清单，不是“整体准确率”或全部页面百分比。
空气质量图表和原始模型可能与国内官方监测值明显不同，必须保留参考性质提示。

## 来源一致性

请求、天气缓存、城市摘要、生活建议、历史快照按来源和配置修订隔离。
切换时清除页面旧快照、图表、高低温、太阳时刻和预警；旧配置的迟到回调不能写入新页面。
首页、48小时、多日、六项指标和空气质量详情由同一份映射后的数据构造，不各自另查第三方数值。
QWeather的有效原生AQI不会被Open-Meteo趋势覆盖。

## 隐私与免费条件

- 不嵌入维护者密钥、账户、邮箱或电话，不向免费源发送个人 API、精确地址、设备标识或安装ID。
- 仅请求HTTPS官方域名，不跟随重定向；坐标发送前降到小数点后两位，保留本机地址展示逻辑。
- 天气服务仍会看到请求IP及近似坐标，不承诺网络级匿名。官方说明日志可能保留坐标，90天后删除。
- 免费档只适用非商用，仍有限流及署名要求，不称无限调用；变量较多的请求可能按多次计费额度计算。
- 用户填入个人API后，免费源不再补齐缺失天气字段；独立全国排名、地址解析与应用更新不属于Open-Meteo天气请求。
