# 免费天气源提醒与指示条修复

## 使用行为

- 第一次在未配置个人 API 的情况下进入天气页时，提示当前使用 Open-Meteo 免费源、模型数据的局限以及缺少的功能。
- 从 API 配置页返回且有效源仍为免费源，或清除个人 API 后回到天气页，会再次提醒。成功切换到个人彩云或和风后不显示免费源提示。
- 已确认的同一次配置状态会保存在本机。刷新、城市切换、前后台切换、页面重建和普通重启不反复提醒。
- 首次引导及权限说明完成后才显示提醒，避免多层弹窗互相遮挡。

## 提醒样式

- 28dp 圆角玻璃面板，复用 `DetailGlassSurface` 对天气页背景采样并模糊，不采样弹窗自身或模糊前景文字。
- 按钮采用 16dp 圆角、同一玻璃材质以及 `WeatherFrostedBorderDrawable` 描边高光。弹窗后方独立压暗 62%。
- 按来源、数据限制和个人 API 建议分段，提供“配置个人 API”和“我知道了”。大字号时正文可滚动，操作按钮保留在面板底部。
- 明确强烈建议配置个人彩云或和风 API，以改善国内天气信息的准确性和功能可用性；具体覆盖仍取决于个人 API 版本、权限和实际天气条件。

## 指示器

- 自填版 AQI 详情改为与内置版相同的 270° 渐变填充仪表盘，等级文字同时保留深浅色对比度处理。
- 两版共用体感温差几何规则：零温差居中；非零温差越过中央留白，至少有 8dp 的颜色填充段。±1°C 圆点落在相应填充侧，极值不越出轨道。
- 保持指示条现有基准点、配色、光圈和不播放入场动画的规则。

## 本次验证

- 自填工程 150 项单元测试，内置工程 118 项单元测试通过；两版 Release 构建及构建要求的 lint 检查通过。
- OPPO Android 16：自填版 6 项设备测试及内置版 2 项设备测试通过。覆盖正负一度/零温差的真实 Canvas 像素、深浅色 AQI、提醒事件及持久化、玻璃背景真实采样、描边、压暗和配置状态摘要。
- 真机首页确认首次免费提醒；点击配置按钮并返回未配置状态，再次出现提醒。个人源不出现免费提示、重复事件不弹窗，由同一控制器设备测试验证。
- 视觉证据只包含指示器及弹窗自身，未采集个人城市、API 输入内容或系统通知栏。设备测试不修改个人 API；深浅色设置在测试结束后恢复。

上述测试验证界面行为和指示器几何，不构成对气象预测准确率的承诺。
