# 后续版本发布说明模板

将下方模板复制到新版本的 GitHub Release 正文，替换所有占位内容。
只填写实际完成且验证过的功能，不把计划中的内容标记为已发布。
同时更新根目录 CHANGELOG.md，并把未发布内容归入新版本。

```markdown
# 云松天气 版本号

<!-- yunsong-version-code: 实际Android构建号 -->

发布日期：YYYY-MM-DD

## 版本简介

用一两句话说明这次更新的主要变化。

## 新增

- 已完成的新功能。

## 优化

- 已完成的体验或性能改进。

## 修复

- 已修复的问题。

## 下载与升级

- 安装包：yunsong-weather-版本号.apk
- 最低系统版本及兼容性变化。
- 覆盖升级、接口配置或权限变化的注意事项。
- 校验值：SHA256SUMS.txt

## 已知限制

- 仍存在的限制；无新增限制时说明即可。
```

删除不适用的小节和占位文字后再发布。更新检测使用正式标签、有效 APK 和实际数字构建号；
模板中的占位构建号不能直接用于正式 Release。
